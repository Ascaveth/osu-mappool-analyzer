## Modern Web Guidance

- `dark-mode-toggle`: returning to the OS preference restores system mode rather than persisting a redundant override. Rule used: "If the target matches the current system preference, the user is undoing their adjustment". Persistence and OS changes remain handled by `next-themes`.
- `dark-mode`: root `color-scheme` and viewport metadata advertise the supported schemes. Rule used: "Apply the `color-scheme` property to the `html` element or the `:root` pseudo-class."

The default daisyUI themes are disabled and existing tokens supply the component colors, following the [daisyUI configuration documentation](https://daisyui.com/docs/config/). This keeps theme selection in `next-themes` rather than adding a second theme controller.
